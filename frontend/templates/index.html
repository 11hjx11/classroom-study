项目介绍

ClassVision - 课堂专注度智能分析系统

项目简介

ClassVision 是一个基于深度学习的课堂专注度智能分析系统，通过计算机视觉技术自动分析课堂中学生的专注状态。

核心功能

  • 智能抽帧：从视频中自动均匀抽取关键帧
  • 人脸检测：基于 YOLOv8 的高精度人脸检测
  • 姿态估计：MediaPipe Face Mesh 分析头部姿态
  • 行为识别：智能识别 10 种课堂行为状态
  • 报告导出：支持 CSV 格式数据导出

技术栈

  • 前端：HTML5 + CSS3 + JavaScript
  • 后端：Flask (Python Web Framework)
  • 深度学习：YOLOv8, MediaPipe, TensorFlow/PyTorch
  • 数据处理：Pandas, NumPy

# 克隆项目
git clone https://github.com/your-repo/classvision.git

# 安装依赖
